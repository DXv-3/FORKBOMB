# FORKBOMB vision

GitHub already holds more working software than any company could invent alone. FORKBOMB turns that inventory into a growth engine.

## Core belief

Reuse is not a shortcut. Reuse is the product surface. When every useful unit on GitHub is findable, snappable, trusted, and rewarded, builders ship faster and the market compounds.

## Ecosystem layers

1. **Pieces** — the smallest useful units: functions, workflows, schemas, prompts, containers, UI blocks.
2. **Connectors** — shared interfaces so pieces compose without custom glue every time.
3. **Trust** — licenses, tests, provenance, and security signals on every brick.
4. **People** — docs, examples, maintainers, and places to ask.
5. **Value** — hosted edges, support, premium packs, sponsorships, marketplace listings.
6. **Feedback** — usage, issues, and releases that steer what gets built next.

## Sustainable growth loop

```
Discover → Snap → Ship → Earn → Improve → Discover
```

Every cycle leaves more bricks in better shape. That is the market.

## What success looks like

- A builder can assemble a working product from known pieces in one sitting.
- Piece authors get credit, traffic, and paths to revenue.
- Connectors stay boring and stable so innovation happens in the bricks.
- New markets form around packs of pieces (agents, commerce, infra, creative tools).
