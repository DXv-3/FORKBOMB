# Packs

A **pack** is a set of pieces + connectors aimed at one job. Format: `packs/<name>/pack.json` with `id`, `name`, `version`, `license`, `summary`, `job`, `pieces`, `connectors`, and optional `stages`.

| Pack | Job |
| --- | --- |
| [`forkbomb-core`](forkbomb-core/pack.json) | Run FORKBOMB on itself — the operating loop as a pack |
| [`gradients`](gradients/pack.json) | Every gradient, live: 556 MIT gradients + WebGL mesh/aurora/grain + dot effects |
