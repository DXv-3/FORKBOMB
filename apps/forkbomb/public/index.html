FORKBOMB — every app, one origin

A zero-dependency creative toolbox assembled from permissively licensed parts found across GitHub. Paste code, live-code shaders, explore gradients and choreograph particles.

  • Paste →

    Share code with syntax highlighting, expiry and a JSON API.

  • Shaders →

    WebGL2 live-coding playground with a composable GLSL library.

  • Gradients →

    556 MIT gradients, mesh, aurora and grain with copy-ready CSS/GLSL.

  • Dots Studio →

    Particle shapes, morphs, physics and timelines, exportable as embeds.
