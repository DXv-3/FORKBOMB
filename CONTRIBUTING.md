# Contributing to FORKBOMB

Bring bricks. Improve seams. Grow the market.

## Add a piece

1. Drop the code or workflow under `toolkit/<category>/`.
2. Add a catalog entry in `pieces/entries/<id>.json` matching `pieces/schema.json`.
3. Update the table in `pieces/CATALOG.md`.
4. Name the connector it speaks.
5. Keep the license clear and the source link honest.

## Add a connector

1. Create `connectors/<name>/SPEC.md` and optional `schema.json`.
2. Document success and failure shapes.
3. Link at least one piece that uses it.

## Tone

Build. Ship. Leave the bin fuller than you found it.
